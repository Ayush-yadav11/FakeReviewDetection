# Fake Review Detection

A text classifier that tells computer-generated product reviews from ones written by people.

**[Try the detector in your browser →](https://ayush-yadav11.github.io/FakeReviewDetection/)** Paste any review; the page scores it with the trained model and marks the words that moved the score. Nothing leaves your browser.

## Results

Trained on 30,324 reviews and scored once on the 10,108 held out (a stratified 75/25 split, seed 42):

| Model | Accuracy | Train time |
|---|---|---|
| SVC (RBF kernel) | **90.03%** | about 5 minutes |
| Logistic regression | 88.54% | about 1 second |
| Random forest | 85.98% | about 45 seconds |
| Logistic regression, page model (words seen 3+ times) | 88.56% | about 3 seconds |

Per-class precision, recall and confusion matrices are in [`results/metrics.json`](results/metrics.json).

What the model leans on: generated reviews use words like *problem*, *reason* and *replace*, and the phrase "the only reason" appears in 888 generated reviews against 51 written by people. Reviews by people hedge more (*even*, *though*, *without*) and run longer: 74 words on average against 61.

## How it works

1. Strip punctuation and drop English stopwords (NLTK), keeping each word's case.
2. Count the remaining words and weight them with TF-IDF.
3. Score with a classifier: logistic regression, SVC or random forest.

The project page runs step 3 with the logistic regression's exported weights ([`site/model.json`](site/model.json), 16,338 words, 0.39 MB), in the same order as `train.py`, so both give a review the same score.

## Run it

```bash
pip install -r requirements.txt
python train.py          # all three models, about 6 minutes
python train.py --fast   # logistic regression only
```

`train.py` writes `results/metrics.json` and the page model `site/model.json`. The exploration notebook is [`main.ipynb`](main.ipynb).

## Data

`fake reviews dataset.csv`: 40,432 Amazon product reviews from ten categories, half original (`OR`) and half generated by GPT-2 (`CG`), from J. Salminen et al., *Creating and detecting fake reviews of online products*, Journal of Retailing and Consumer Services, 2022 ([doi:10.1016/j.jretconser.2021.102771](https://doi.org/10.1016/j.jretconser.2021.102771)).

The model learned from GPT-2 text, so reviews written by newer language models can score as original.
